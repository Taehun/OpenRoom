# Storefront pages

Body copy for the pages the footer links to. `write_online_store_pages` is not
granted to the app, so these are entered by hand in **Online Store → Pages**:
create a page with the title in the file's first heading, switch the editor to
`</>` (HTML), and paste the body below it.

Every page here describes the OpenRoom demo store honestly. The shipping and
returns figures match the promises on the homepage
(`templates/index.json`, section `trust_row`) — change them together.
